# 초과기록 (`/overtime`)

2026년 10월 1일부터 인사랑 「초과근무기록관리」가 켜졌다. 초과 신청이 걸린 시간에는 한 시간 칸마다
인사랑에서 [확인]을 누르고, 못 누른 칸은 미기록 사유를 쓴다. 안내를 받아도 오늘 내 건에서 어느 칸을
누르고 무엇을 쓰는지는 바로 안 보인다. 이 화면은 그 한 가지를 한다.

## 하는 일

- 날짜, 내 근무시간(유연근무 포함), 초과 시간, 자리 비운 때(식사, 외출, 현장)를 넣는다.
- 칸마다 [확인] 또는 미기록 사유(쓸 말 예시)가 나온다. 근무제외시간으로 넣을 것도 따로 나온다.
- 「이 날 초과로 남기기」를 누른 날은 다음 날 확인자료 카드가 맨 위에 뜬다. 「올렸어요」로 지운다.
- 진동 알림(웹 푸시)을 켜면 [확인] 칸마다, 그리고 다음 날 09:10 에 울린다.
- 순서 여덟 줄과 묻고 답하기(찾기 되는 목록)를 함께 둔다.

## 하지 않는 일

- 칸을 대신 누르지 않는다. 인사랑에 접속하지 않는다. 직접 누르도록 알려 줄 뿐이다.
- 넣은 값은 이 기기에만 남는다. 모델을 부르지 않는다. 진동 알림을 켠 기기만 울릴 시각과 칸 번호·날짜를
  서버에 맡기고, 울린 것은 바로 지운다(`src/core/overtime/push.ts`).
- 수당 금액이나 인정 시간을 셈하지 않는다. 공제와 버림은 기관 산정의 몫이다.

## 규칙이 사는 곳

판단은 `src/core/overtime/plan.ts` 한 곳에만 있다. 묻고 답하기는 `src/core/overtime/faq.ts` 이다.

근거는 세 층이고 위층이 먼저다. **법령**(지방공무원 수당 등에 관한 규정 제15조) → **지침**(지방공무원보수업무 등
처리지침) → **사용 안내**(인사랑 화면 쓰는 법). 모두 다시 쓴 것이고 원문·캡처·파일을 싣지 않는다.
공개 페이지라서 시스템 보안 세부, 감시 방식, 교육 자리의 예정·검토 발언은 싣지 않는다(검사가 막는다).

- 칸은 정각에서 정각까지. 19:00 정각은 19~20 칸.
- 기록 칸은 정규 근무시간에 온전히 들어가지 않는 칸. 휴일은 모든 칸.
- 칸 안에 사무실에서 일한 틈이 1분이라도 있으면 [확인], 없으면 사유.
- 식사는 사유만 쓰고 근무제외시간에는 넣지 않는다. 외출은 둘 다. 현장은 사유만.

규칙이 바뀌면(예: 사유 없으면 상신 불가) 이 파일과 검사를 같이 고친다.

## 검사

```
node --experimental-strip-types --import ./scripts/ts-hooks.mjs scripts/check-overtime.mjs
```

사용 안내와 규정에 적힌 사례(18:00~20:40 세 칸, 식사·근무·외출, 유연근무, 휴일 낮, 아침 짧은 틈,
평일 1시간 공제, 1시간 미만)를 그대로 넣어 본다. 진동 알림은 지어낸 키로 암호를 풀어 보고 보내기·지우기를 본다.

## 진동 알림 켜기(서버)

```
node scripts/make-vapid.mjs >> .env.local    # 한 번만. 개인키는 서버 밖에 두지 않는다
```

키가 없으면 알림 켜기만 꺼지고 나머지는 그대로 돈다. 맡은 알림은 `~/.patrol-overtime-push.json`
(`OVERTIME_PUSH_FILE` 로 바꿀 수 있음)에 있고, 서버가 뜰 때 `src/instrumentation.ts` 가 시계를 켠다.
